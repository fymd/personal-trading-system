# 个人交易系统：可运行 MVP

本分支在原有 v2.3 规则手册基础上增加一个本地可运行的 Streamlit 决策工作台。

## 当前功能

- 板块轮动阶段初步判定：主升、补涨、退潮、冷门、观察
- 按 v2.3 阈值计算 RS、成交额变化等指标的规则判定
- 提供带日期历史记录的连续确认检查
- 四项共振检查和入场 Checklist
- 仓位计算：风险预算、方向性止损校验（多头止损低于入场价、空头止损高于入场价）、成本估算、阶段/信心/外部环境系数、资金占比上限
- 输入校验：拒绝无穷/非数值行情、重复板块日期、无效价格及超范围风险参数
- SQLite 本地交易日志，支持 CSV 导出
- 组合风险管理：汇总持仓止损风险、总仓位、行业敞口和单标的集中度，并按用户设定阈值告警
- 历史风险分析：基于导入的价格历史计算标的日收益相关性，基于账户净值历史计算当前/最大回撤及预警
- CSV 导入与分析结果导出

## 启动

需要 Python 3.10 或更高版本。

```bash
python -m venv .venv
# Windows PowerShell:
.venv\\Scripts\\Activate.ps1
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

浏览器打开 Streamlit 显示的本地地址，通常为 http://localhost:8501 。

## CSV 格式

必需列：

```csv
sector,ret3_pct,ret5_pct,rs3_pct,rs5_pct,amount_ratio,close,ma5
半导体,1.5,3.2,1.1,2.3,1.25,100,98
```

- 百分比填写数值，例如 1.5 代表 1.5%，不是 0.015。
- RS = 板块同期涨跌幅 - 沪深300同期涨跌幅。
- amount_ratio = 近3日日均成交额 / 近10日日均成交额。
- 可选 date 列用于按板块检查连续确认。带日期的历史行必须按交易日连续提供；同一板块同一日期不允许重复。

## 组合风险管理

在“组合风险管理”页面导入或编辑持仓快照 CSV，字段为：

```csv
symbol,sector,market_value,risk_amount
510300,宽基指数,180000,3600
半导体ETF,半导体,150000,7500
芯片设备A,半导体,80000,5200
```

- `market_value`：持仓当前市值（账户计价货币）。
- `risk_amount`：从当前持仓到止损位的预计亏损金额，建议计入费用和滑点。
- 同一标的多条记录会合并计算集中度。
- 默认阈值：组合止损风险 3%、总仓位 100%、单行业 35%、单标的 20%；可在页面调整。
- 数据由用户导入或填写，不连接券商、不自动下单或调整持仓。风险金额是估算值，不是最大亏损保证。

## 历史风险分析

“历史风险分析”页面接受两类独立 CSV：

价格历史（用于收益率相关性）：

```csv
date,ETF_A,ETF_B,ETF_C
2026-01-05,100,50,80
2026-01-06,101,50.5,79.5
2026-01-07,99,49.5,80.8
2026-01-08,102,51,80.2
```

- 每行一个交易日，每个标的一列，建议使用复权收盘价。
- 程序先计算日收益率，再按两两共同有效观察计算 Pearson 相关系数；共同样本不足时结果为空。
- 相关性是历史统计关系，不表示因果，也不保证未来稳定。

账户净值历史（用于回撤）：

```csv
date,nav
2026-01-05,1000000
2026-01-06,1020000
2026-01-07,990000
```

- 最大回撤按净值相对历史运行峰值的跌幅计算。
- 当前回撤触及用户设置的阈值时显示预警。
- 两份数据均由用户导入；本功能不自动获取账户净值或价格，不代表实时监控。

## 重要边界

- 当前不提供行情 API 接入，不自动采集行情、主力资金、PCR 或海外数据。
- 当前不连接券商，不发送订单，不构成自动交易系统。
- 单日导入时，主升/退潮连续确认无法验证，界面会标注为初步判断。
- 计划亏损是估算值；跳空、流动性、涨跌停和执行滑点可能使真实损失更大。
- SQLite 文件 `trading_journal.db` 默认保存在应用目录，请自行备份；不要把含个人交易记录的数据库提交到公开仓库。

## 后续建议

1. 接入可靠且有授权的数据源，并保存原始数据及时间戳。
2. 完成历史回测、样本外验证、手续费/滑点/停牌涨跌停建模。
3. 增加多标的组合风险、相关性和总风险敞口约束。
4. 模拟交易稳定后，再单独评估券商接口；默认保持人工确认。
