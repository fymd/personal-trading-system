# 研究路线与版本记录

## 当前版本
- **V1.1（规格初稿）：** 市场择时模块，包含指数趋势、市场宽度、成交活跃度、市场情绪、外部风险、市场状态、风险预算、数据闸门和历史验证要求。未完成程序实现、回测或模拟交易验收。
- **V1.0（理论总纲）：** 建立全球宏观联动、A股市场环境、板块行业、龙头短线、趋势波段、组合风控和策略验证架构。
- **跨版本强制原则：** U0–U3不确定性分级和风险否决优先于所有评分和选股信号。

## 后续路线
| 版本 | 模块 | 交付 |
|---|---|---|
| V1.2 | 板块强度与行业轮动 | 相对强度、成交占比、持续性、主线识别 |
| V1.3 | 龙头短线引擎 | 龙头地位、情绪周期、入场和退出 |
| V1.4 | 趋势波段引擎 | 行业景气、基本面、趋势结构、估值风险 |
| V1.5 | 买卖点与组合风控 | 仓位、止损、相关性、流动性、组合回撤 |
| V1.6 | 数据与回测基础设施 | 数据字典、时间对齐、交易成本、回测引擎 |
| V2.0 | 系统整合与验证 | Walk-forward、样本外评估、模拟交易验收 |

## 未决事项
1. 多指数趋势评分汇总方法和权重。
2. 市场宽度股票池及特殊证券处理。
3. 涨停、跌停、炸板和连板数据源及历史口径。
4. 外部变量时间对齐规则与数据源。
5. 评分阈值和风险预算系数的实证验证。
6. 数据缺失、异常和事件冲突时的降级策略。
7. 单元测试、集成测试和回测报告模板。

## 变更纪律
每次修改记录日期、版本、文件、修改内容和原因、数据区间、样本内外结果、风险与失效条件。禁止仅因短期回测变差而随意调参；参数变更须记录假设，并用未参与调参的数据重新验证。
