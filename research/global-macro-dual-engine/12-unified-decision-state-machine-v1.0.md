# 双引擎交易系统统一决策状态机 V1.0

> 状态：理论规格初稿；评分、阈值、持续确认天数和状态转换参数均待历史验证。本文不代表已验证策略，也不构成投资建议。

## 1. 目的与设计原则

将市场择时、情绪周期、主线与龙头识别、双引擎入场、仓位管理和退出规则整合为统一决策流程，避免模块各自评分后发生冲突。

核心原则：
1. 分层决策，不把市场状态、个股许可和组合风险混成一个总分。
2. 硬性否决优先于评分；致命风险不得被其他维度高分抵消。
3. 市场许可不等于个股买入信号；个股优秀不等于组合有风险承载能力。
4. 龙头短线与趋势波段分别判断、分别管理；组合风险统一合并。
5. 数据质量、不确定性和交易可执行性是前置条件。
6. 无法可靠判断时降低风险、等待证据，不强行给出方向。

## 2. 三级决策架构

### L1：市场风险许可

输入：全球宏观与跨市场风险、A股多指数趋势、市场宽度、成交活跃度、情绪周期、流动性和重大事件。

输出：ACTIVE / CAUTIOUS / WAIT / RISK_CONTROL。

### L2：个股交易许可

输入：数据质量、市场许可、板块方向、个股地位、价格结构、风险收益和信号有效期。

输出：READY / WAITING / NO_TRADE，并分别标注龙头短线或趋势波段引擎。

### L3：组合风险许可

输入：已有持仓、单票/行业/主题暴露、相关性、计划风险总和、账户回撤、流动性和压力情景。

输出：APPROVED / REDUCE_RISK / BLOCK_NEW_RISK。

### 执行层

综合前三层及持仓状态，输出 BUY / HOLD / REDUCE / EXIT / NO_TRADE。BUY必须同时满足市场许可、个股许可、组合许可和执行条件；任何一层否决均不得下单。

## 3. L1市场状态与初始评分

沿用市场择时V1.1五维研究框架：

| 维度 | 权重 |
|---|---:|
| 多指数趋势 | 25 |
| 市场宽度 | 25 |
| 成交活跃度 | 20 |
| 市场情绪 | 20 |
| 全球外部环境 | 10 |
| 合计 | 100 |

初始状态映射：

| 状态 | 分数区间 | 风险预算乘数 |
|---|---:|---:|
| ACTIVE | 80–100 | 1.00 |
| CAUTIOUS | 60–79 | 0.60 |
| WAIT | 40–59 | 0.25 |
| RISK_CONTROL | 0–39 | 0 |

说明：
- 乘数作用于基础风险预算，不是账户仓位百分比。
- 数据质量失败、重大事件无法判断、系统性流动性风险、U2/U3风险或组合熔断可直接否决新增风险。
- 高评分不能覆盖否决条件。
- ACTIVE仅表示允许寻找机会，不代表市场中所有股票均可买入。
- 状态分数与乘数均为待验证假设。

## 4. 状态转换与防抖

### 升级确认

从较低风险状态升级，需要：
1. 评分进入目标区间；
2. 指数趋势、宽度、成交和情绪等关键证据具有一致性；
3. 数据质量合格；
4. 不存在风险否决；
5. 满足预先定义的持续确认条件。

连续确认天数和具体指标组合暂不固定，须通过历史样本、样本外测试和模拟交易确定。

### 降级快速通道

明确的系统性风险、流动性异常、重大逻辑证伪或组合风险触发时，可以立即降级，不等待连续确认。

### 防止状态频繁切换

记录每日原始评分、最终状态、状态变更原因和持续时间。可研究滞回区间、连续确认和变化幅度门槛；不得仅为减少交易而延迟风险降级。

## 5. L2个股七道关口

| 关口 | 核心检查 | 未通过处理 |
|---|---|---|
| G1 数据质量 | 完整性、准确性、时间戳、可用时间、异常值 | NO_TRADE |
| G2 市场环境 | 对应引擎是否获得市场风险许可 | 等待/NO_TRADE |
| G3 板块方向 | 主线、行业趋势或合格独立趋势是否成立 | WAITING/NO_TRADE |
| G4 个股地位 | 龙头身份、相对强度、产业竞争力与流动性 | WAITING/NO_TRADE |
| G5 价格结构 | 是否出现预先定义的有效入场形态 | WAITING |
| G6 风险收益 | 失效点、潜在收益、成本、滑点和尾部风险 | NO_TRADE |
| G7 组合风险 | 新增风险是否在组合限额内 | NO_TRADE/缩小规模 |

状态定义：
- READY：前置关口通过，存在有效信号；仍须完成订单价格、信号有效期和执行检查。
- WAITING：研究逻辑仍成立，但触发条件尚未出现或证据未确认。
- NO_TRADE：数据、逻辑、风险、信号有效期或执行条件不合格。

READY不等于BUY；BUY是执行层最终指令。

## 6. 双引擎分别授权

### 龙头短线（目标3–5个交易日）

重点证据：情绪周期、主线强度、龙头身份、板块扩散、资金承接、短线价格结构和次日溢价。

市场强势但情绪退潮时，不得仅凭市场评分提高短线风险。龙头地位丧失、板块负反馈扩散或短线逻辑证伪时，按退出规则处理。

### 趋势波段（目标2–8周）

重点证据：行业景气、企业质量与盈利兑现、估值、相对强度、中期趋势结构和产业逻辑。

短期情绪走弱不自动要求全部趋势仓退出；但产业逻辑证伪、价格趋势破坏或组合风险触发时必须重新评估或退出。

同一证券若同时被两个引擎持有，必须在组合层合并风险，不能将其视为分散。

## 7. L3组合风险许可

沿用V1.5研究起点（均待验证）：
- 龙头单笔计划风险：账户净值0.25%–0.50%。
- 趋势单笔计划风险：账户净值0.50%–0.75%。
- 全部持仓计划风险总和：账户净值2%–3%以内。
- 单只股票市值暴露：净值10%以内。
- 单一行业市值暴露：净值25%以内。
- 高度相关主题/产业链暴露：净值30%以内。

组合层必须检查：
1. 新交易加入后的计划风险总和；
2. 行业与主题集中度；
3. 持仓间相关性及共同风险因子；
4. 极端跳空、跌停、停牌和流动性枯竭情景；
5. 账户回撤及风险审查状态。

计划风险不等于最大可能损失。风险预算不通过时，优先拒绝新增风险或降低相关暴露，而不是降低止损标准以迁就仓位。

## 8. 冲突处理规则

| 冲突 | 统一处理 |
|---|---|
| 市场强势、情绪退潮 | 市场层可保持观察，但短线引擎降级；趋势引擎单独检查中期逻辑 |
| 产业逻辑良好、价格结构破坏 | 保留产业研究结论，但原交易价格失效规则仍有效 |
| 个股评分高、组合集中度超限 | 候选资格保留，新增交易被组合层否决 |
| 个股强势、系统性风险触发 | 系统性风险优先，控制组合风险 |
| 技术形态良好、关键数据缺失 | 数据闸门否决，不以技术形态补足数据 |
| 情绪和板块信号矛盾 | 降低置信度，等待更多证据，不强行合成单一结论 |

冲突处理优先级：
1. 交易安全、系统性风险和流动性；
2. 数据质量与不确定性否决；
3. 逻辑证伪；
4. 价格结构失效；
5. 市场、情绪与板块环境；
6. 盈利管理和时间效率。

该顺序是风险处置优先级，不代表必须等待前一项发生后才能处理后一项。

## 9. 每日标准输出

每日研究至少形成四部分：

### A. 市场状态表
- 日期、数据截止时间、市场状态、原始评分、各维度得分；
- 情绪周期、全球环境、风险否决；
- 状态置信度、状态变化原因和风险预算乘数。

### B. 候选标的表
- 股票代码、名称、交易引擎、所属板块；
- 主线/龙头身份、研究状态（READY/WAITING/NO_TRADE）；
- 入场形态、触发价或结构条件、失效条件、信号有效期；
- 主要风险和证据来源。

### C. 组合风险表
- 当前持仓、单票/行业/主题暴露；
- 计划风险总和、相关性与共同风险；
- 账户回撤、流动性压力；
- 组合许可状态及限制原因。

### D. 执行决策表
- BUY / HOLD / REDUCE / EXIT / NO_TRADE；
- 数量和价格须基于当时可得数据及交易规则计算；
- 未通过条件、数据缺口和禁止执行原因；
- 明确区分信号时间、信息可用时间和实际成交时间。

若关键字段缺失，输出“无法判断/待补数据”，不得编造分数或许可。

## 10. 状态机伪流程（概念规格）

1. 检查数据完整性、时间对齐、可用时间及异常标记。
2. 若关键数据不合格：相关决策输出NO_TRADE，并记录缺失原因。
3. 检查U级不确定性、重大事件、流动性和系统性风险否决。
4. 计算市场状态与风险预算乘数；执行状态升级确认或风险降级快速通道。
5. 分别评估龙头短线与趋势波段市场许可。
6. 对每只候选股票依次检查G1–G7。
7. 检查已有持仓的逻辑、价格、时间、盈利和组合退出条件。
8. 计算新交易后的组合风险与集中度。
9. 组合层批准、缩小规模或否决。
10. 输出执行指令、理由、数据截止时间、失效条件和审计记录。

## 11. 历史验证要求

必须检验：
- 市场状态升级/降级的稳定性及滞回参数；
- 各评分维度的信息重叠和重复计分；
- 不同市场状态下两引擎的条件期望收益；
- 风险否决的误报与漏报；
- 不同组合相关性和压力情景下的尾部损失；
- READY到实际成交的可执行性和信号过期率；
- 参数在样本外、不同年份、不同波动环境中的稳定性。

验证必须使用点时可得数据，防止未来函数、幸存者偏差和事后分类；纳入交易费用、滑点、涨跌停不可成交、停牌、T+1及历史交易制度变化。保留负面结果，不以单一回测指标选择模型。

## 12. 未决事项

1. 市场状态升级的持续确认天数与滞回参数。
2. 市场评分与情绪周期之间的指标去重方法。
3. 全球宏观风险否决的量化边界及事件分级。
4. 两引擎在CAUTIOUS、WAIT环境下的差异化许可。
5. READY状态的信号有效期及订单执行窗口。
6. 相关性估计窗口、压力相关性和共同风险因子定义。
7. 组合计划风险的统一计算方法及跳空损失压力参数。
8. 状态置信度的定义与校准。
9. 每日数据截止时间、盘中更新和收盘后决策的时间治理。
10. 全部状态转换与人工覆盖的审计日志规则。

## 13. 版本状态

V1.0仅完成理论架构与规则优先级设计。下一阶段优先制定统一指标字典、数据源分级、时间戳/可用时间规范、缺失值和异常值处理、重复指标识别及数据质量验收标准。暂不进入程序实现，待理论规格稳定后再规划数据与回测基础设施。
