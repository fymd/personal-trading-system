# 市场环境识别与择时模块 V1.1

状态：程序规格初稿，未完成数据验证、回测或参数验收。所有分值、权重和阈值均为待检验假设。

## 1. 输入与输出
输入五组：指数趋势（沪深300、中证500、中证1000、创业板指、科创50等OHLCV）；市场宽度（上涨/下跌/平盘数量）；成交活跃度（全市场成交额）；市场情绪（涨停、跌停、炸板、连板高度及晋级）；外部环境（全球股指、美元、人民币、美国实际利率、VIX等）。

输出：评估日期、数据质量、五类分数、总分、市场状态、不确定性等级、是否允许新开仓、风险预算系数和评分原因。记录交易日、时区、发布时间、数据可用时间、来源和质量状态。

## 2. 指数趋势（25分）
初始构想：收盘价高于20日均线5分；20日均线高于5日前均线5分；20日均线高于60日均线5分；60日均线高于20日前均线5分；多指数趋势共振5分。观察沪深300、中证500、中证1000、创业板指、科创50。**多指数如何汇总为25分尚未定稿**，需明确权重、缺失处理和归一化，可先用等权基线并做敏感性测试。

## 3. 市场宽度（25分）
上涨比例=上涨股票数/(上涨股票数+下跌股票数)。平盘暂不进入分母；停牌、无有效报价、新股特殊阶段单独标记。固定股票池口径。

初始分档：≥70%为25分；60%–70%为20分；50%–60%为15分；40%–50%为10分；30%–40%为5分；<30%为0分。另计算5日和20日均值，代码中统一边界规则。

## 4. 成交活跃度（20分）
成交额比率=当日全市场成交额/过去20个交易日成交额均值。
初始分档：≥1.30为20分；1.15–1.30为16分；1.00–1.15为12分；0.85–1.00为8分；0.70–0.85为4分；<0.70为0分。放量不必然利好，必须结合指数收益和市场宽度：上涨且宽度改善的放量可能代表增量参与；下跌且宽度恶化的放量可能代表抛压；横盘放量可能代表分歧。

## 5. 市场情绪（20分）
初始分配：涨停数5分、跌停数5分（反向计分）、炸板率5分（反向计分）、连板高度及晋级表现5分。
炸板率=触及涨停但收盘未封住的股票数/触及涨停的股票数。处理分母为零、盘中触板识别、不同板块涨跌幅制度、ST及特殊制度。连板高度结合晋级率、跌停数和市场宽度。

## 6. 外部环境（10分）
全球主要股指趋势、美国实际利率变化、美元指数变化、VIX变化、人民币汇率及外部金融压力，各初始2分。禁止机械映射单一变量方向：美债收益率下降可能源于通胀回落，也可能源于衰退担忧；美元走弱对不同A股行业影响不同。记录驱动因素、传导路径和不确定性。外部数据按A股当时可获得时间对齐。

## 7. 总分与市场状态
总分=趋势+宽度+成交+情绪+外部。
初始阈值：80–100积极参与；60–79谨慎参与；40–59观望；0–39风险控制。
初始风险预算系数：积极1.00、谨慎0.60、观望0.25、风险控制0。系数乘以已验证的基础组合风险预算，不代表账户仓位比例；仍受止损、相关性、流动性和组合硬限制约束。

## 8. 风险闸门
数据质量检查→事件真实性和不确定性检查→市场风险评估→评分→状态和预算输出。U2/U3时不得依赖该事件开仓；系统性流动性风险可触发组合风险控制。关键数据缺失、异常或时间错位时输出DATA_ERROR或受限状态，不得静默填零。评分高不能覆盖风险否决；事件不确定也不自动意味着既有仓位全部清仓。

## 9. 两引擎差异
积极：两引擎正常评估；谨慎：龙头更重视情绪、承接和退出，趋势更重视中期趋势与行业景气；观望：以观察为主；风险控制：暂停新开仓。两类策略分别回测。

```python
def market_regime_engine(data):
    quality = check_data_quality(data)
    if not quality.ok:
        return {"status": "DATA_ERROR", "allow_new_position": False}
    uncertainty = check_uncertainty_and_risk(data)
    scores = {
        "trend": calculate_index_trend(data),
        "breadth": calculate_market_breadth(data),
        "volume": calculate_volume_activity(data),
        "sentiment": calculate_market_sentiment(data),
        "external": calculate_global_risk(data),
    }
    total = sum(scores.values())
    if uncertainty in ("U2", "U3") or has_systemic_risk(data):
        return {"score": total, "scores": scores,
                "status": "RISK_CONTROL", "allow_new_position": False}
    if total >= 80: status = "ACTIVE"
    elif total >= 60: status = "CAUTIOUS"
    elif total >= 40: status = "WAIT"
    else: status = "RISK_CONTROL"
    multiplier = {"ACTIVE": 1.00, "CAUTIOUS": 0.60,
                  "WAIT": 0.25, "RISK_CONTROL": 0.00}[status]
    return {"score": total, "scores": scores, "status": status,
            "risk_budget_multiplier": multiplier,
            "allow_new_position": status in ("ACTIVE", "CAUTIOUS")}
```
