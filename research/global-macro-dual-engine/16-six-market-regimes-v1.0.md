# A股六类市场状态识别模型 V1.0

- 版本：V1.0（理论规格初稿）
- 日期：2026-11-10
- 状态：待历史验证；状态名称和授权规则为研究框架，不代表已验证预测能力。

## 1. 目标与原则

将市场环境识别转化为双引擎交易授权和组合风险管理。市场状态不是对下一交易日涨跌的确定性预测，而是对当前机会条件、风险水平和允许行动的结构化描述。

原则：
1. 硬性风险否决优先于评分。
2. 多维证据共同决定状态，单一指标不得独立定类。
3. 状态升级需多证据和持续性确认；明确风险恶化允许快速降级。
4. 龙头短线和趋势波段分别授权，组合风险统一核算。
5. 数据质量不足时输出低置信度或暂停判断。

## 2. 五个识别维度

| 维度 | 主要输入 | 识别问题 |
|---|---|---|
| 指数趋势 | 多指数趋势、均线结构、20日收益 | 市场方向是否明确 |
| 市场宽度 | 上涨占比、20/60日宽度、新高新低 | 上涨是否广泛参与 |
| 成交活跃度 | 全市场成交额、相对20日均值 | 参与程度是否增强 |
| 市场情绪 | 涨跌停、连板晋级、炸板率、次日溢价 | 风险偏好是否改善 |
| 波动与风险 | 历史波动率、最大回撤、下跌扩散 | 风险是否放大 |

前四项主要描述机会环境，第五项主要承担风险监控和否决职责。不得因成交放大或涨停增加而忽略波动、回撤和下跌扩散。

## 3. 六类市场状态

### S1 趋势扩张（TREND_EXPANSION）
指数趋势向上，市场宽度同步改善，成交活跃，强势板块具有持续性。龙头短线与趋势波段均可优先寻找机会，但个股许可、信号质量和组合风险仍需独立审核。

### S2 趋势收敛（TREND_CONTRACTION）
指数仍向上，但宽度恶化，或成交、强势股承接与趋势不再配合。降低追高，趋势仓优先管理已有仓位，重点观察指数与宽度背离。

### S3 震荡轮动（RANGE_ROTATION）
指数方向不明，板块轮动较快，持续性不足。龙头短线只参与辨识度和持续性较高的局部机会；趋势波段等待趋势形成，控制交易频率。

### S4 弱势修复（WEAK_RECOVERY）
指数仍弱，但宽度、下跌扩散或核心股表现开始改善。短线仅观察冰点后的试错和修复；趋势波段以观察为主。修复不等于新周期启动。

### S5 弱势退潮（WEAK_DOWNTREND）
指数偏弱、宽度恶化、下跌扩散，强势股持续失去溢价。原则上回避普通接力和高位追涨，趋势仓复核逻辑与风险，停止普通新增高风险仓位。

### S6 系统性风险（SYSTEMIC_RISK）
出现流动性冲击、跨市场风险传染、极端波动或重大数据异常等。作为独立风险否决层，原则上禁止新增风险并重新评估组合流动性和潜在损失。S6不应被其他维度高分抵消。

## 4. 初步授权矩阵

| 状态 | 龙头短线 | 趋势波段 | 新增风险原则 |
|---|---|---|---|
| S1 | 优先寻找合格机会 | 优先寻找趋势共振 | 按正常风险许可 |
| S2 | 精选、避免追高 | 谨慎管理 | 降低新增风险 |
| S3 | 精选、快进快出 | 等待趋势 | 控制频率和风险 |
| S4 | 有限风险试错 | 观察为主 | 仅有限试探 |
| S5 | 原则上回避普通接力 | 防守管理 | 停止普通新增风险 |
| S6 | 禁止新增风险 | 组合风险审查 | 风险否决优先 |

此表是授权原则，不替代既有风险预算数值，不自动触发清仓或具体仓位比例。

## 5. 状态识别顺序

1. **风险否决：**检查系统性风险、流动性冲击、极端波动、重大事件和数据质量问题。
2. **趋势与宽度：**识别两者同步或背离。趋势向上且宽度改善，检查S1；趋势向上但宽度恶化，检查S2；方向不明检查S3；指数偏弱而宽度改善检查S4；两者同步恶化检查S5。
3. **成交与情绪确认：**识别参与是否广泛、是否有持续性，避免少数股票上涨造成假象。
4. **双引擎授权：**分别判断龙头和趋势许可，再由组合风险层统一审批。

该流程是证据组织顺序，不是未经验证的机械分类公式。

## 6. 状态转换和置信度

每日记录当前状态、前一日状态、升级/维持/降级、置信度、支持证据、反向证据、风险否决、双引擎授权和组合许可。

- 升级：通常要求多个维度共同改善并持续确认，不能因单日放量上涨直接升级。
- 降级：系统性风险、流动性恶化或关键结构破坏可触发快速降级。
- 置信度：高/中/低，必须同时记录反向证据和数据质量。
- 过渡状态：证据冲突或状态切换未确认时，允许标记为“过渡/低置信度”，不强迫归类。

## 7. 状态冲突原则

当指数、宽度、成交、情绪和波动风险相互矛盾时：
- 先排查时间戳、股票池和数据质量。
- 识别指标是否重复表达同一风险因子，避免重复计分。
- 让风险否决维度优先于机会维度。
- 对方向冲突降低置信度、缩小许可，不用简单平均掩盖矛盾。
- 证据不足时输出“暂不能判断/WAIT”，而不是强行归入最乐观状态。

## 8. 验证要求

需检验状态区分能力、状态转换概率、双引擎在不同状态下的风险调整表现，以及相对“指数+宽度”基准的增量价值。采用时间顺序Walk-forward和样本外测试；防止未来函数、幸存者偏差和事后分类；计入费用、滑点、涨跌停不可成交、停牌和T+1。

## 9. 当前版本结论

- 六类状态作为研究分类建立。
- 沿用既有市场指标字典，不新增重复计分。
- S6保留独立风险否决优先级。
- 双引擎分别授权，组合风险统一核算。
- 暂不设置固定数值阈值，不调整市场择时五维权重。
- 在历史验证与模拟交易验收前，不升级为实盘规则。
