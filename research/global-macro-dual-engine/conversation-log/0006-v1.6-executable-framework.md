# 对话研究记录 0006：可执行投资框架 V1.6

- 日期：2026-11-10
- 仓库：fymd/personal-trading-system
- 目录：research/global-macro-dual-engine/
- 主题：将理论研究收敛为可执行的A股双引擎投资流程。

## 1. 用户要求与系统目标

用户明确要求直接给出可用、可落地的投资框架。系统采用六步决策链：市场择时 → 板块择优 → 个股择强 → 买点择机 → 仓位管理 → 卖出退出；前置数据质量和U0–U3不确定性闸门，后置交易复盘与统计验证。

两个引擎保持分离：
- 龙头短线：目标持仓3–5个交易日，重视板块地位、市场辨识度、换手承接和短期情绪。
- 趋势波段：目标持仓2–8周，重视行业景气、企业盈利、现金流、估值和中期趋势。

## 2. V1.6关键设计

- 市场择时沿用V1.1五维100分模型：指数趋势25、市场宽度25、成交活跃20、市场情绪20、全球外部环境10；状态ACTIVE/CAUTIOUS/WAIT/RISK_CONTROL及风险预算乘数1.00/0.60/0.25/0。
- 板块择优沿用V1.2五维评分：相对强度25、成交资金活跃20、趋势结构20、持续性扩散20、催化基本面15。
- 龙头候选沿用V1.3评分结构：板块核心25、辨识度20、成交换手20、资金承接15、催化持续10、技术形态10。
- 趋势候选沿用V1.4评分结构：行业景气20、盈利增长20、企业竞争力15、现金流财务质量10、资金持续15、趋势结构15、估值风险收益5。
- 仓位与组合风控以V1.5为唯一正式研究参数来源，避免简化示例与细化风险规格冲突。
- 宏观变量只用于识别背景、风险和产业传导，必须由A股价格、成交、市场宽度和板块表现验证。
- 没有合格机会时输出NO_TRADE；数据失败、U2/U3、流动性或交易制度不可行时不得用高评分覆盖否决。
- 每日固定盘前、盘中、盘后流程，并要求记录未交易机会、失败案例和规则变更。
- 所有权重、分数、风险比例和阈值均为待验证假设，不是已验证盈利策略。

## 3. 对先前简化参数的纠偏

此前对话曾给出单笔统一风险0.5%、总计划风险1.5%、单票20%、总仓位50%的简化示例。该组数字不纳入正式框架，以免与V1.5分策略风险预算及单票/行业/主题组合上限冲突。V1.6明确以V1.5为准。

## 4. 实施路线

固定数据字典与时间治理 → 数据质量和不确定性闸门 → 市场择时 → 板块轮动 → 龙头与趋势双引擎 → 仓位及组合风险 → 回测、Walk-forward、样本外和模拟交易验收。

V1.6是可执行研究与模拟交易操作手册规格初稿，未完成程序实现、历史回测、样本外测试或模拟交易验收，不构成投资建议。
