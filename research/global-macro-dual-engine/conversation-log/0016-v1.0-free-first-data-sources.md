# 研究对话日志 0016：免费优先的数据源评估

- 日期：2026-11-10
- 研究阶段：第26阶段
- 关联文档：`26-data-source-availability-quality-cost-v1.0.md`
- 状态：公开来源初步评估；尚未完成数据下载、质量验收或授权法律审查

## 用户明确偏好

尽量不付费，优先采用公开来源、官方来源和免费工具。数据建设应围绕龙头短线3–5交易日、趋势波段2–8周的日频研究，不为当前不需要的高频数据购买服务。

## 主要决策

1. 免费优先、官方优先、多源核验、自建指标、保留来源和版本。
2. 官方来源优先用于事实核验：上交所、深交所、巨潮资讯、国家统计局、国家外汇管理局、中国债券信息网及央行公开资料。
3. BaoStock作为日频行情候选主源；AKShare用于多源采集和交叉核验；CNEquity作为自托管数据湖候选。
4. Tushare不购买积分；Level-2、逐笔盘口、分钟线策略数据、历史一致预期和付费研报暂缓。
5. 市场宽度、情绪、板块强弱等尽可能从原始行情自行计算，减少对第三方加工字段的依赖。
6. 免费、公开可查、可批量抓取、可保存、可再分发是不同的权利边界，必须分别登记。
7. GitHub只保存研究规格、来源URL、数据字典和质量报告摘要，不上传未确认授权的原始数据。
8. 先以小样本覆盖多板块、退市、停复牌、公司行为和宽基指数，完成双源核验，再扩展全市场。
