## 1. 用户要求与研究脉络

用户在V1.6可执行投资框架之后继续推进理论研究，并明确先完善理论，不急于代码实现。本轮依次讨论：

2. A股情绪周期阶段、六维评分及与市场择时的联合使用；
3. 主线板块识别、龙头身份分类、核心/跟风/补涨识别及主线失效；
4. 龙头短线与趋势波段的入场形态、失效条件、风险收益计算和交易前检查。

## 2. 情绪周期模型 V1.0

情绪周期不是简单涨停家数统计，而是市场风险偏好及其扩散/收缩。观察市场整体、短线生态和板块资金扩散。阶段包括冰点/衰退末期、启动/试错、发酵/扩散、高潮、分歧和退潮；分歧是压力测试状态，阶段可跳跃或无法分类。

初始六维评分：涨停跌停结构20、连板高度与晋级率20、炸板率与封板质量15、强势股次日溢价20、龙头核心股表现15、板块扩散10。暂定状态映射：80–100强势发酵、60–79温和活跃、40–59分歧观察、20–39明显退潮、0–19极端低迷。均为待验证假设。

明确口径：晋级率按前一日连板层级分组；炸板率须固定触板定义；强势股次日溢价同时报告均值、中位数、分位数及负收益比例；特殊证券、停牌、新股和不同涨跌幅制度要单独处理。静态分数之外记录3/5日变化。情绪不能覆盖数据/U等级/流动性/组合否决。

## 3. 主线与龙头识别 V1.0

主线五层确认：市场关注、内部强度、持续性、资金认可、可验证逻辑。五维初始评分：相对强度20、板块扩散20、成交资金20、持续性与分歧修复25、产业/催化15。暂定80+核心主线候选、65–79次主线/强势方向、50–64潜在热点、低于50暂不列重点；分级为观察、候选、确认、衰退。分歧后修复是确认的重要证据，但不设统一固定天数。

龙头六维评分：市场辨识度20、板块带动20、资金承接20、相对强度15、关键节点表现15、逻辑关联10。区分空间龙头、容量龙头、情绪龙头和产业龙头；身份可能重合，不能将连板最高等同于波段最优。股票分类包括核心龙头、次核心、跟风、补涨和独立趋势股。主线切换需多日相对强度、成交、持续性和扩散共同验证，单日涨幅不能确认。

## 4. 双引擎入场信号 V1.0

统一七道关口：数据质量、市场环境、板块方向、个股地位、价格结构、风险收益、组合风险。通过关口仅进入下单评估，不等于必须交易。

龙头短线四类形态：启动确认、分歧转强、突破后回踩确认、加速行情例外。趋势波段四类形态：中期趋势突破、上升趋势回踩、平台整理后二次突破、产业与价格趋势共振。强调突破要结合收盘结构、成交、板块、相对强度及后续维持；缩量回踩不自动等于安全。

下单前写明结构失效点、逻辑失效条件和风险许可失效条件。仓位以V1.5风险预算为准；示例为假设计算，计划风险不等于最大可能损失。风险收益比和期望值须结合交易成本、滑点、跳空、未成交、T+1和涨跌停检验。信号过期、追价越界、风险超限、数据异常或U2/U3等情况输出NO_TRADE。

## 5. 关键方法论纪律

- 所有评分、权重、分档和形态触发条件均为待验证研究假设。
- 指数、宽度、情绪和板块指标可能重复计分，需检验相关性和增量信息。
- 相关性不等于因果；不得事后贴主线/龙头标签。
- 历史验证使用当时可得数据、历史成分和点时行业/概念分类，防止未来函数与幸存者偏差。
- 龙头短线和趋势波段分别统计，组合风险统一管理。
- 证据不足或无法可靠判断时降低风险、观望或NO_TRADE，不为保持交易频率强行交易。
