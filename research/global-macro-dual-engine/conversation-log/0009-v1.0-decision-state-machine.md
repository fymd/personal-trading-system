# 对话记录 0009：统一决策状态机 V1.0

日期：2026-11-10

## 本轮目标
在市场择时、情绪周期、主线/龙头识别、入场信号、仓位管理和退出模型之后，建立统一决策状态机，避免各模块各自打分、互相冲突。

## 核心架构
采用三级决策：
1. 市场风险许可：ACTIVE / CAUTIOUS / WAIT / RISK_CONTROL。
2. 个股交易许可：READY / WAITING / NO_TRADE，分别评估龙头短线和趋势波段。
3. 组合风险许可：APPROVED / REDUCE_RISK / BLOCK_NEW_RISK。
4. 执行层：BUY / HOLD / REDUCE / EXIT / NO_TRADE。

## 关键原则
- 硬性否决优先于评分；高分不能抵消数据、逻辑、系统性风险或组合风险否决。
- 市场许可不等于个股买入信号；READY也不等于BUY。
- 龙头短线与趋势波段分别授权，但相同股票及相关资产的组合风险必须合并。
- 状态升级需要多证据与持续确认；明确风险恶化可快速降级，不等待确认。
- 冲突时优先处理系统性风险、数据质量、不确定性、逻辑证伪和价格结构失效。
- 每日输出市场状态、候选标的、组合风险和最终执行决策，并保留时间戳与原因。
- 所有评分、阈值和风险参数仍是待验证假设。

## 用户决策偏好
继续采用保守决策：当事件、政策、数据或潜在影响无法可靠判断时，不强行推断或交易；优先等待证据、降低风险。
