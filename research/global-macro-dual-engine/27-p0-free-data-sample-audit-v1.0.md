# 第27阶段：P0免费数据源小样本试采集与质量验收方案 V1.0

- 日期：2026-11-10
- 状态：样本与采集程序已准备；未完成外部API实际下载和数据质量实测
- 目标：以最小成本验证BaoStock、AKShare和官方公开资料是否足以支撑第一批日频研究数据。

## 1. 本阶段结论边界

本阶段已核对公开API文档、字段定义和已知数据风险，并准备了可运行的Python试采集脚本。当前执行环境没有安装baostock和akshare，且不能直接访问这些第三方API，因此没有生成真实行情样本、没有计算实际差异率，也不能宣布任何数据源已通过质量验收。

应区分：
- 已完成：样本设计、字段对照、单位风险识别、采集脚本准备、官方资料核查。
- 待执行：用户本地运行脚本、真实下载、源间比对、历史覆盖率与数据完整性验收。
- 未完成：点时财务历史版本、退市股票全覆盖、授权法律审查和正式回测准入。

## 3. 字段映射与口径

### BaoStock
其公开Python API文档列出字段：date、code、open、high、low、close、preclose、volume、amount、adjustflag、turn、tradestatus、pctChg、isST等；文档定义volume单位为股、amount单位为人民币元，tradestatus=0表示停牌、1表示正常交易；adjustflag=3表示不复权。
官方文档：https://github.com/baostock/baostock/blob/master/docs/pythonAPI.md

### AKShare
历史行情接口stock_zh_a_hist提供日期、开高低收、成交量、成交额、涨跌幅、换手率等字段，复权参数支持不复权/前复权/后复权。
项目文档：https://github.com/akfamily/akshare

重要处理：
- AKShare不同接口/上游的成交量单位可能不同；历史股票接口字段口径必须按当前安装版本文档和返回值验证。
- 本轮脚本保留AKShare原始成交量字段，不在未核实单位前将其换算成股，也不把成交量纳入自动差异结论。
- 成交额统一按人民币元比较，但仍需抽样核验。
- 价格比较只使用不复权数据；不得将前复权/后复权价格与不复权价格混比。
- AKShare项目的数据提示页记录过特定股票后复权OHLC出现负值的案例，因此复权数据必须独立执行异常检查。
风险提示：https://github.com/akfamily/akshare/blob/main/docs/data_tips.md

## 4. BaoStock历史证券列表测试

采集脚本会调用query_all_stock，分别抓取2019-12-31和2021-12-31的历史证券列表，并检查600747是否出现在对应历史日期列表中。
这只能检验所选历史日期的列表可得性，不能证明全历史退市证券完整；还需要与交易所上市、终止上市公告交叉核验。

## 5. 官方数据的可用性边界

交易所公开网页可用于查询和核验市场信息，但不能假设官方完整历史行情批量下载一定免费。上交所历史数据产品页面列明历史数据按年度订阅，故不将完整交易所历史行情库纳入免费P0主源；公开页面/日度概况仅作核验用途。
参考：https://english.sse.com.cn/markets/dataservice/products/

本轮官方核验策略：
- 证券状态、交易规则、停复牌、退市：交易所公告和公开资料。
- 公司财务与事件：巨潮资讯/交易所披露，后续必须记录公告真实发布时间。
- 历史日线：先以BaoStock和AKShare候选源试采集，交易所公开数据只在可免费查询范围内抽样核验。

## 6. 采集程序

已准备文件：`p0_free_data_audit.py`（V1.1，本轮修正版本）。
运行环境需安装Python及依赖：
`pip install pandas baostock akshare`（无需pyarrow）

运行：
`python p0_free_data_audit.py`

V1.1修正：BaoStock股票与指数使用不同字段列表，避免把个股专用字段请求到指数接口；记录脚本版本和依赖版本；统一输出标准化CSV，不要求额外安装Parquet引擎。指数行情独立采集，不与个股行情混用字段。\n\n程序将创建`p0_free_data_audit/`目录，输出：
- raw：两类来源的原始CSV；
- normalized：标准化CSV；
- manifest_and_results.json：采集时间、接口状态、异常和样本结果；
- comparison_summary.csv：按日期对齐后的OHLC和成交额差异摘要。

脚本不会把接口失败、空数据或缺失文件当成零差异；会将缺失文件标记为MISSING_FILE，将空结果标记为EMPTY_SOURCE。脚本只做初步比对，不替代完整的数据质量审计。

## 7. 质量判定规则

### 通过条件（需全部满足）
1. 主源与辅助源在样本区间有合理覆盖，且数据日期可解释。
2. OHLC和成交额口径统一后，差异在可解释范围内；任何系统性差异均需定位。
3. 不存在重复日期记录、明显错序、负价格或OHLC逻辑错误。
4. 停牌日、无成交日和非交易日能够区分。
5. 退市样本的历史行情及历史证券列表有证据支持。
6. 采集失败、字段变化和缺失均有日志。
7. 原始数据可追溯到来源、下载时间和接口版本。
8. 数据许可与使用条款已登记。

### 不通过/暂停条件
- 关键字段定义不清或单位未确认；
- 历史样本明显缺失且无法解释；
- 复权口径混杂；
- 退市证券被静默排除；
- 接口频繁失败或字段结构漂移；
- 数据来源或使用权利不明确。

## 8. 本轮待执行动作

1. 在可联网的本地Python环境安装依赖并运行脚本。
2. 将`manifest_and_results.json`、`comparison_summary.csv`及必要的原始样本上传/提供。
3. 检查BaoStock历史证券列表中600747是否出现。
4. 对照AKShare当前版本成交量单位，必要时更新转换逻辑后再做成交量比较。
5. 逐证券检查缺失交易日、异常OHLC、成交额差异和重复记录。
6. 抽样核验交易所公告和停复牌记录。
7. 形成实测报告后，决定是否将BaoStock定为日线候选主源、AKShare作为交叉核验源。

## 9. 阶段决定

暂定组合仍为“BaoStock候选主源 + AKShare交叉核验 + 官方公开资料核验”。这只是待实测的工作假设，不是通过验收的结论。任何正式回测都必须等待真实采集和质量测试完成。
