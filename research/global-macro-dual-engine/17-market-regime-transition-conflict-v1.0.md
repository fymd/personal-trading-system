# 市场状态转换与证据冲突处理模型 V1.0

- 日期：2026-11-10
- 状态：理论规格初稿，待历史验证
- 目标：规范六类市场状态的转换、证据冲突和风险授权。

## 1. 证据优先级
- P0：系统性风险、流动性冲击、极端波动，可直接否决新增风险。
- P1：数据质量、时间错位、重大不确定性；暂停依赖不可靠数据的判断。
- P2：指数趋势、市场宽度、下跌扩散，决定市场结构。
- P3：成交活跃度、市场情绪，确认参与程度和风险偏好。
- P4：板块、龙头、个股信号，只能在上层许可内寻找机会。

全球宏观属于重要外部背景，须经汇率、利率、资金流及A股价格行为验证，不机械取代A股自身结构。

## 2. 典型冲突处理
| 冲突 | 处理 |
|---|---|
| 指数涨、宽度恶化 | 检查S2趋势收敛，不直接判顶 |
| 指数跌、宽度改善 | 检查S4弱势修复，不直接判新周期 |
| 指数涨、成交放大、情绪降温 | 检查S2/S3并降低置信度 |
| 指数横盘、宽度改善、成交稳定 | 观察S3向S4的可能变化 |
| 龙头强、板块退潮 | 区分个股抱团与板块扩张 |
| 全球风险偏好改善、A股偏弱 | 不直接升级A股状态 |

## 3. 状态转换
S1→S2分为上涨质量下降预警、趋势内部收敛候选、结构性破坏降级。宽度恶化是预警证据，不单独触发全面退出。

S4→S1分为内部修复、指数确认、资金确认、主线确认四层。修复不等于新周期启动。

S6为覆盖状态。解除S6后重新评估市场，不自动恢复此前状态。

## 4. 滞回与置信度
- 升级需要多维证据持续确认。
- 普通降级通常要求持续性；明确系统风险、流动性恶化或关键结构破坏可快速降级。
- 置信度分高/中/低，记录支持证据、反向证据和数据质量。
- 低置信度表示证据不足，不表示必然下跌；必要时WAIT或暂停分类。

## 5. 日报字段
日期、数据质量、五维证据、当前状态、前一状态、转换方向、置信度、支持/反向证据、风险否决、龙头授权、趋势授权、组合许可、最终执行及人工覆盖原因。

## 6. 验证
使用时间顺序Walk-forward检验状态转换稳定性、转换后未来收益/回撤、不同市场阶段表现及双引擎增量价值。禁止未来函数、事后标签和幸存者偏差。所有边界待校准。

## 7. 当前结论
本模型是证据组织和风险授权规格，不是市场预测器；不新增未经验证的硬阈值，不覆盖既有风险否决原则。
