# 个人交易系统（数据驱动版）

一套以**数据分析为底层支撑**的个人交易系统模板，结合模型每日预测（入场/出场时间 + 板块推荐），强调纪律执行与长期存活。

仓库地址：https://github.com/fymd/personal-trading-system

---

## 项目内容

| 文件 | 说明 |
|------|------|
| `个人交易系统_数据驱动版_v2.1.md` | 完整交易系统模板（推荐使用） |
| `个人交易系统_数据驱动版_v2.0.md` | 上一版本备份 |
| `style-research-report.css` | 投研报告型单页仪表盘样式 |
| `style-sidebar-dashboard.css` | 侧边栏导航型仪表盘样式 |

---

## 系统核心原则

1. **数据优先** — 所有决策建立在可量化数据之上
2. **信号共振** — 趋势 + 资金 + 模型板块至少两项同向才允许开仓
3. **仓位纪律** — 单笔风险、总风险、回撤硬限制不可违反
4. **长期存活** — 把生存放在收益前面

---

## 主要模块

### 0. 数据分析支撑层
- 数据来源与更新频率
- 每日核心数据看板 + 指标解读规则
- 共振规则定义

### 1–4. 核心交易规则
- 交易目标与模型角色边界
- 市场状态过滤（Regime Filter）
- 入场 Checklist + 多级出场规则
- 仓位计算公式、完整计算示例、硬性风险限制

### 5. 每日标准工作流
- 开盘前 / 盘中 / 收盘后固定流程

### 6–7. 日志与复盘
- 交易日志（含模型相关字段）
- 每周强制复盘模板

### 8. 模型评估与迭代
- 每周跟踪指标与降权/暂停条件

### 9. 心理与行为管理
- 禁止交易状态、常见错误应对、情绪评分

### 10. 策略切换与失效机制
- 明确的停止 / 降权条件

## 使用方法

1. 下载或克隆本仓库
2. 打开 `个人交易系统_数据驱动版_v2.0.md`
3. 把所有【】里的内容替换成自己的规则与参数
4. 复制到 Notion / Obsidian / 语雀 等工具中使用
5. **每笔交易前必须过 Checklist**
6. **每周日强制完成复盘**

```bash
git clone https://github.com/fymd/personal-trading-system.git
```

## 仪表盘样式说明

本仓库提供两套纯 CSS 样式，可用于后续开发可视化界面：

### 1. 投研报告型（`style-research-report.css`）
- 干净明亮、无侧边栏
- 适合每日快速浏览、一页看完核心信息
- 报告感强，阅读优先

### 2. 侧边栏导航型（`style-sidebar-dashboard.css`）
- 左侧深色导航 + 右侧内容区
- 适合做成完整可操作的交易系统前端
- 产品感、结构化、易扩展

直接在 HTML 中引入对应 CSS 文件即可使用其中的设计变量与组件样式。
